Frequently Asked Questions

Frequently Asked Questions / 常见问题

  • How do I set up an AI provider?
    Open the app → Settings → API Provider. Choose a provider, enter your API Key, Base URL, and Model, then tap Test Connection. How do I set up an AI provider?
    English

    Open the app → Settings → API Provider. Choose a provider, enter your API Key, Base URL, and Model, then tap Test Connection.

    中文

    如何配置 AI 提供商？
    打开 App → 设置 → API 提供商。选择供应商，填写 API Key、Base URL 和 Model，然后点击「测试连接」。

  • How does Sync iCloud work?
    Open Settings → Sync iCloud and sign in with your Apple account. Calendar, chat history, and Butler Claw data can sync via your private iCloud database. Sync is optional; the app works locally without it. How does Sync iCloud work?
    English

    Open Settings → Sync iCloud and sign in with your Apple account. Calendar, chat history, and Butler Claw data can sync via your private iCloud database. Sync is optional; the app works locally without it.

    中文

    同步 iCloud 如何使用？
    打开 设置 → 同步 iCloud，使用 Apple 账户登录。日历、对话记录和 Butler Claw 数据可通过 iCloud 私有数据库同步。同步为可选功能，不登录也可本地正常使用。

  • Are my API keys uploaded to the cloud?
    No. API keys are stored in the macOS Keychain on your device and are not uploaded to iCloud or our servers. Are my API keys uploaded to the cloud?
    English

    No. API keys are stored in the macOS Keychain on your device and are not uploaded to iCloud or our servers.

    中文

    API Key 会上传到云端吗？
    不会。API Key 仅保存在本机 macOS Keychain 中，不会上传至 iCloud 或我们的服务器。

  • How do I use Butler Claw?
    Switch to Butler Claw mode, attach files if needed, describe the task and deadline, review the plan, and confirm to schedule it on your calendar. How do I use Butler Claw?
    English

    Switch to Butler Claw mode, attach files if needed, describe the task and deadline, review the plan, and confirm to schedule it on your calendar.

    中文

    如何使用 Butler Claw？
    切换到 Butler Claw 模式，按需添加附件，描述任务与截止时间，确认执行计划后排入日历即可。

  • How do I erase local data?
    Open Settings → General → Erase Local Usage Data. This clears local usage on this Mac only; it does not delete iCloud data or sign you out. How do I erase local data?
    English

    Open Settings → General → Erase Local Usage Data. This clears local usage on this Mac only; it does not delete iCloud data or sign you out.

    中文

    如何抹除本机数据？
    打开 设置 → 通用 → 抹除本机使用数据。此操作仅清除本机使用记录，不会删除 iCloud 数据，也不会退出登录。

  • What are the system requirements?
    macOS on Apple Silicon or Intel. An API key from a supported provider, or a local GGUF model for on-device inference. What are the system requirements?
    English

    macOS on Apple Silicon or Intel. An API key from a supported provider, or a local GGUF model for on-device inference.

    中文

    系统要求是什么？
    macOS（Apple 芯片或 Intel）。需自备支持的 API 提供商密钥，或使用本机 GGUF 本地模型。

About the App

Agent Butler Client is a macOS productivity app that helps you plan schedules, chat with AI, and automate document tasks with Butler Claw. It connects to third-party LLM APIs using credentials you provide, or runs local models on your Mac.

About the App / 关于 App

English

Agent Butler Client is a macOS productivity app that helps you plan schedules, chat with AI, and automate document tasks with Butler Claw. It connects to third-party LLM APIs using credentials you provide, or runs local models on your Mac.

中文

Agent Butler Client 是一款 macOS 效率 App，帮助您制定日程、与 AI 对话，并通过 Butler Claw 自动完成文档类任务。App 使用您提供的密钥连接第三方大模型 API，也支持在本机运行本地模型。
