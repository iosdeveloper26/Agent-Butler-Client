How do I set up a model?

Settings → API. For a cloud model, enter the key, base URL, and model name, then test the connection. A local model can be loaded in the app. The composer chooses cloud or local for that turn.

How does Work Brief work?

Open the Work Brief. Fill in who you are and what to consider at work, then save. Ask & Do, Code & Write, and Multi-agent read the short summary.

Code & Write will not run?

Connect a model first, choose a folder, and confirm when the app asks to install the local runner.

How do I use Code & Write?

Choose a folder, describe the task, and read the command and the result in the chat. The app does not open an unrestricted terminal.

Sync iCloud?

Optional. Settings → Sync iCloud, then Sign in with Apple and upload. Keys, model weights, and workspace files are not uploaded.

How do I erase local data?

Settings → General → Erase Local Usage Data. This Mac only. It does not delete iCloud or sign you out.
