What you can do with Agent Butler

Agent Loop and personal AI settings let you shape how the assistant thinks and acts. Start from the workflows below, then keep exploring.

Schedule Planning

Describe what you need. Review a time slot, then add it to the calendar.

Q&A and Planning

Chat with attachments, refine a goal, and generate batches of tasks.

Butler Claw

Schedule document work. The app runs it in the background and saves the result.

Custom workflows

Talk with the AI to structure a task flow, hand selected steps to the model, and fold AI into the way you already work.

Private by default

API keys stay in the macOS Keychain. They are not uploaded to iCloud.

Local models

Run a GGUF model on your Mac when you want to keep inference on-device.

Data Privacy

Your calendar, chat, and Butler Claw files stay on this Mac unless you turn on Sync iCloud. API keys are stored in the macOS Keychain and are never uploaded.

If you use a cloud model, prompts go to the provider you choose. Local models stay on-device. Read the full Data Privacy page for details.
