UI preview & mode introduction

Starter

Ask & Do

Ask & Do is included in Starter. In one sentence, it is your assistant. In this mode you hold an ordinary conversation with the agent. You can also call the built-in MCP tools for basic file editing, and for work in external apps and plugins. Several workflows are already here, including goal-oriented planning, so a task is easier to lay out.

What it can do

Daily questions

Ask in the same chat: type, attach a picture or a file, or hold to talk. Calendar and mail are part of this daily work.

Calendar. A time such as “basketball at 9am” shows a confirmation card first. The event is written only after you agree. Add on the main window puts one event on the calendar without the model. Calendar · Watch

Mail. Gmail and Outlook connect through Nylas. iCloud uses IMAP on this Mac. Today’s inbox lists the sender and a short summary. The model can draft a reply, and it sends only after you edit it and agree. Mail · Watch
