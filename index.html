FAQ

Short answers about Agent Butler Client.

What is it?

A personalized AI assistant on macOS. Natural language becomes calendar items; confirmed jobs can edit files, write reports, and look up public pages. It is a native Mac app, not a command-line installer.

How do I install it?

Download it from the Mac App Store. In Settings → API, add a cloud key or install MLX. Auto Mode requires a loaded MLX model first.

Which models?

Cloud: Groq and OpenAI-compatible endpoints (Moonshot, Together, OpenRouter, DashScope, and others). Local: in-app MLX or llama.cpp via llama-server. Auto Mode is MLX only.

Do Planning and Claw read Who I am?

Yes. After you fill the two briefs, Planning, Butler Claw, and Auto Mode all receive those constraints. Closing the Work Brief window saves them.

Can it run arbitrary terminal commands?

No. The Mac App Store sandbox does not allow arbitrary terminal processes. File tools only touch the sandbox and your chosen workspace. Commands meant for your Mac are shown for you to copy or run.

Is my data uploaded?

On this Mac by default. Optional iCloud for calendar and chats. API keys, model weights, and workspace files stay local. Cloud models send prompts to the provider you choose.

What does it cost?

The app is $19.99 one-time (or the local App Store price). Cloud model cost is your API bill; on-device MLX has no extra model API fee.

Data Privacy

Your calendar, chats, Work Brief, and workspace files stay on this Mac unless you turn on Sync iCloud. API keys stay in the Keychain.

On this Mac

Calendar, chat, Work Brief, window memories, and Butler Claw files are stored locally. Files in the folder you choose are not uploaded. API keys are never sent to iCloud or to our servers.

Cloud models

If you use a cloud API, prompts go only to the provider you configure. On-device MLX stays on this Mac. Read the full Data Privacy page for details.
