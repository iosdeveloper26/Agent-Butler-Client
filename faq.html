FAQ

Short answers about Agent Butler Client.

What is it?

A Mac assistant. Ask & Do confirms a calendar card, Code & Write runs in a folder you choose, and Multi-agent uses the roles already in the app. A named plugin is called from this chat.

Is this an early product?

Yes. Agent Butler Client is in active development: you can use it today on the Mac App Store, and we keep shipping refinements. Expect the product to grow; the core workflows are already here.

How do I install it?

Download it from the Mac App Store. In Settings → API, add a cloud key or use a local model.

Which models?

Use a cloud model you configure, or a local model on this Mac. A cloud model sends that turn to the provider you chose.

Does the Work Brief apply in every mode?

Yes. After you save it, Ask & Do, Code & Write, and Multi-agent read the short summary.

Can it run arbitrary terminal commands?

No. Work stays in the folder you choose. Installing the local runner asks you to confirm. The app does not open an unrestricted terminal.

Is my data uploaded?

On this Mac by default. Optional iCloud for calendar and chats. API keys, model weights, and workspace files stay local. Cloud models send prompts to the provider you choose.

What does it cost?

Starter is $9 a month, Standard is $15 a month, and Scale is $30 a month. A cloud model is billed by the provider you choose.

Should I trust every plan the AI writes?

No. Treat plans and files as a draft. The model can miss details, and it only knows what you have shared. Review anything that matters before you act. See AI safety.
