FAQ

Short answers about Agent Butler Client.

What is it?

A personalized AI assistant on macOS. Natural language becomes calendar items; confirmed jobs can edit files, write reports, and look up public pages. It is a native Mac app, not a command-line installer.

Is this an early product?

Yes. Agent Butler Client is in active development: you can use it today on the Mac App Store, and we keep shipping refinements. Expect the product to grow; the core workflows are already here.

How do I install it?

Download it from the Mac App Store. In Settings → API, add a cloud key or install MLX. Auto Mode can use either.

Which models?

Cloud: Groq and OpenAI-compatible endpoints (Moonshot, Together, OpenRouter, DashScope, and others). Local: in-app MLX or llama.cpp via llama-server. Auto Mode uses the cloud API or on-device MLX.

Do Planning and Claw read Who I am?

Yes. After you fill the two briefs, Planning, Butler Claw, and Auto Mode all receive those constraints. Closing the Work Brief window saves them.

Can it run arbitrary terminal commands?

No arbitrary shell. File tools stay in the sandbox and your chosen workspace. Developer mode in Butler Claw or Auto Butler can run an allowlisted subset (python3, pytest, swift, node, ruby, go) after you install a helper once. Other commands are copied for you to paste into Terminal.

Is my data uploaded?

On this Mac by default. Optional iCloud for calendar and chats. API keys, model weights, and workspace files stay local. Cloud models send prompts to the provider you choose.

What does it cost?

The app is $19.99 one-time (or the local App Store price). Cloud model cost is your API bill; on-device MLX has no extra model API fee.

Should I trust every plan the AI writes?

No. Treat plans and files as a draft. The model can miss details, and it only knows what you have shared. Review anything that matters before you act. See AI safety.
