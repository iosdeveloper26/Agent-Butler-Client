What it can do

Turn a personal goal into a plan you can follow, put the work on the calendar, and let the Mac finish document and code jobs when they are due.

1

Personalized, executable plans

Use your personal constraints to turn a goal into a plan you can actually follow, register it on the calendar, and break the work into concrete next steps.

2

Register Mac tasks as events

Put PC-side jobs on the calendar—writing a document, generating code, and similar file work—so each task has a time and a deliverable.

3

Run some of those jobs automatically

When a registered task is due, automatically carry out part of the PC-side work, such as writing documents and writing code into your workspace.

Planning · Claw · Auto

One Work Brief. Three tempos.

Butler & Planning

Natural-language chat, attachments, batch plans. “Basketball at 9am” gets a confirmation card; finished plans can land on the calendar.

Butler Claw

Attach files, set a deadline, approve the plan. PDF / Word / sheets / scripts return to the workspace. Due jobs run about 15 minutes before start.

Auto Mode

Its own window; scans the calendar about every 15 minutes. Uses your cloud API or on-device MLX.
